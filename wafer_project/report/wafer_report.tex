\begin{abstract}
A two-dimensional incompressible Navier--Stokes solver for flow through a rack
of six wafers is reviewed, corrected, and independently re-run. The solver uses
a geometry-aligned Marker-and-Cell (MAC) staggered grid with a fractional-step
(projection) method, first-order donor-cell upwind advection and explicit
second-order diffusion. An equal-rack-flow constraint fixes the inlet velocity
of each pitch by a bracketed scalar root solve. Independent reruns reproduce the
audited production inlet speeds and hydraulic resistances, confirm discrete mass
conservation at roundoff ($\sim\!10^{-13}\%$), and recover the resistance
ordering $R_{h,\mathrm{Small}}>R_{h,\mathrm{Medium}}>R_{h,\mathrm{Large}}$.
\end{abstract}

\section{Governing equations and method}
The flow solves the 2-D incompressible Navier--Stokes equations
\begin{align}
\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u}\cdot\nabla)\mathbf{u}
&= -\nabla p + \nu\,\nabla^2 \mathbf{u}, &
\nabla\cdot\mathbf{u} &= 0,
\end{align}
on a geometry-aligned MAC staggered grid. A fractional-step projection advances
the velocity: an explicit predictor (first-order donor-cell upwind advection,
second-order nonuniform diffusion) is followed by a pressure Poisson solve and a
divergence-free correction,
\begin{equation}
\nabla^2 p = \frac{1}{\Delta t}\,\nabla\!\cdot\mathbf{u}^{*},
\qquad
\mathbf{u}^{n+1} = \mathbf{u}^{*} - \Delta t\,\nabla p .
\end{equation}
The discrete gradient (correction) and divergence operators are mutually
adjoint, so the assembled pressure matrix is exactly $-\nabla\!\cdot\nabla$ of
the operators actually applied; this guarantees discrete mass conservation. The
pressure Poisson system is factorized once per grid and reused across all
root-finding evaluations. Boundary conditions: no-slip on the tank side/bottom
walls and all wafer surfaces, prescribed vertical inlet slots at the bottom, and
a $p=0$ open outlet at the top.

\paragraph{Equal-$Q$ control.}
For each pitch the inlet speed $U_\mathrm{in}$ is chosen so the rack flow equals
a common target $Q_0$. This is a bracketed secant iteration with a bisection
safeguard, where every function evaluation is a fully converged CFD solve. It
enforces an integral control constraint; it is not a fit to data.

\section{Code audit and corrections}
The audited bundle was reviewed statically and then exercised. The following
non-numerical corrections were applied (none alters the discretization, so the
reproduced physics is unchanged):
\begin{enumerate}\itemsep2pt
\item \textbf{Hard-coded \texttt{/mnt/data} paths removed.} The driver now
imports the solver from its own directory and writes to \texttt{\$WAFER\_OUT}
(default: current directory), created lazily so the module imports without
filesystem side effects.
\item \textbf{Self-test fixed.} \texttt{mac\_cfd\_adaptive.py} previously called
\texttt{Solver(0.06, 0.0025)}, passing \num{0.0025} where the integer gap-cell
count $n_\mathrm{gap}$ is expected; this collapsed every gap to a single cell.
Corrected to \texttt{Solver(0.06, 20)}.
\item \textbf{Driver de-duplication.} \texttt{run\_production\_equalq.py} (a
byte-identical copy of the audited driver) is now a thin re-export, and the
single-case runners import one shared \texttt{metrics} implementation.
\item \textbf{Stale documentation relabelled.} The legacy FD inlet speeds
($0.5605/0.3000/0.1833$) are now explicitly marked as the earlier
finite-difference model, distinct from the audited MAC values.
\item \textbf{Near-wall note.} A deliberate first-order asymmetry in the $v$
$y$-diffusion stencil is documented in place (left unchanged to preserve the
audited results).
\end{enumerate}

\section{Conclusions}
The MAC projection solver is discretely consistent and mass-conserving to
roundoff. The equal-$Q$ root solve reliably drives $Q_\mathrm{rack}$ to the
common target, and the corrected, portable code reproduces the audited inlet
speeds and hydraulic resistances
($R_h = 14.739 > 2.730 > 0.987$ for Small $>$ Medium $>$ Large). The absolute
inlet speeds of the audited MAC model ($\approx 0.694/0.388/0.237$) differ from
the legacy finite-difference model's values because the numeric target $Q_0$ was
carried over as a fixed constant rather than being redefined self-consistently
for the MAC discretization.
